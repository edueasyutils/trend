1 AGENTS.md에 "정보 획득 능력"을 먼저 적으라는 팁 — @HoneyBiu

X 포스트에서 이렇게 소개됐다. 초보자는 채팅부터 시작하지 말고, AGENTS.md에 Muse의 정보 획득 능력을 먼저 적으라고 전한다. 알 수 없는 질문에는 현재 시간을 먼저 확인하고 검색할 것, GitHub에서 Skill 찾기, FxTwitter로 X 보기, 금융 API(해외 Gate, 국내 신랑·텅쉰 재경 공개 인터페이스), Crawl4AI·Firecrawl로 웹 수집, MCP 마켓·플러그인 활용이 그 내용이다.

주의: 나열된 도구(Skill·FxTwitter·금융 API·Crawl4AI·Firecrawl·MCP 마켓)가 실제 Muse에서 동작하는지는 확인되지 않았다. 포스트에서 소개된 설정 방법 수준으로 읽어야 한다. 또 수집 시점마다 수치가 조금씩 달라, 아래 수치는 조회 시점 기준이다.

2 영국 출시 + aluminium 발음 업데이트 — @zuck

Threads 포스트에서 이렇게 소개됐다. 영국 이용 가능 여부 질문에 답하며, Meta의 Muse 개인 AI 에이전트가 aluminium 단어의 대체 발음을 인식하도록 업데이트됐다고 전한다. 영국 영어 사용자에게 관련 있는 새 기능으로 소개하고, 오늘 에이전트를 써 보라고 권한다.

3 인스타 좋아요를 Memocore로 자동 정리 — @gusevworld

Threads 포스트에서 이렇게 소개됐다. Muse가 인스타그램 좋아요·저장 포스트를 자동으로 컬렉션으로 정리하고 외부 도구 Memocore로 옮길 수 있다고 전한다. 예시는 'Trip to Japan' Memocore 프로젝트를 만들고, Muse에 매일 좋아요를 검토해 일본 관련 콘텐츠를 저장하라고 요청하는 방식이다. 답글에서 작성자는 저녁 자동화를 확인하고, 저장된 관심사를 바탕으로 Claude나 ChatGPT와 연결해 경로를 계획하는 방법도 제안했다고 한다.

주의: Memocore 연동이 실제 동작하는지, 공식 카탈로그 등록 여부는 확인되지 않았다. 작성자 주장 수준으로 읽어야 하며, 댓글은 작성자 본인의 추가 설명뿐이다. 커스텀 MCP 커넥터의 Client ID를 수동으로 붙여넣어야 하는 마찰도 포스트에서 투명하게 밝히고 있다.
