오늘은 순수 사용자 신규 팁은 제한적이지만 공식 기능 소식이 풍부합니다. X에서는 Muse 이메일 주소와 Wonder 모델 업그레이드 같은 공식 발표가, Threads에서는 절약·일정 관리 같은 공식 사용 예시가 새로 나왔습니다. 오늘 Top 5는 X findings 2건과 Threads 직접 열람 3건의 혼합입니다.
읽기 전 안내 — X 항목은 fxtwitter CLI 조회 기록(findings) 기준이며 원문은 미열람입니다. 다만 상위 신규 2건(@finkd Wonder 업그레이드·@alexandr_wang 이메일 주소)은 Newton이 fxtwitter CLI로 본문 전문과 지표를 직접 재확인했습니다. Threads 항목은 직접 열람해 확인한 내용이고, Threads 날짜는 수집 기준(UTC)이며 한국 시간과 하루 어긋날 수 있습니다. "공식 사용 예시" 표시가 붙은 항목은 Meta 공식 계정의 홍보 영상으로, 일반 사용자의 실제 후기가 아니라 공식이 보여주는 사용 예시로 봐주세요. 좋아요 수는 직접 열람 기준이며, 수집 시점 수치와 다를 수 있습니다. 초대·리퍼럴 코드가 들어간 포스트는 내용만 떼어 단독 사례로 쓰지 않으며, 코드값은 기록·소개하지 않습니다.
