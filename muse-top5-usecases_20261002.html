1위 · 신규 도메인

개발자 레포 관리 — GitHub 커넥터

Meta Connect 2026에서 GitHub가 Muse의 업무 커넥터로 공식 명명됐습니다(Notion·Granola·Box와 함께). Meta 공식 Model API cookbook에 따르면 GitHub 에이전트 레시피는 이슈 트리아지, PR 리뷰, Q&A를 지원하고, "agent-fix" 라벨이나 /oc 명령어로 버그픽스 PR을 자동 오픈합니다. 단, 에이전트는 머지할 수 없고 항상 사람이 리뷰한다는 원칙이 명시돼 있습니다.

⚠️ 참고: 이 cookbook은 개발자용 Model API 패턴으로, 소비자 앱 내 GitHub 커넥터의 실제 사용 후기는 아직 확인되지 않았습니다. 또한 Muse는 코딩 에이전트가 아니며, 코딩은 Meta의 Muse Code가 담당합니다.

2위 · 실측

월 $25 절약 + "의사 찾기" — Barron's 실측

Barron's 컬럼니스트는 Muse에게 "Josh Jr."라는 이름을 붙이고 실제 측정했습니다. 사용하지 않는 구독을 찾아내 월 $25를 절약했고, 특히 고위험 구독으로 Sirius XM·Match Group 데이팅 앱·Planet Fitness/Peloton 계열 헬스클럽이 꼽혔습니다. 이번 실측의 신규 포인트는 "Find me a doctor(의사 찾기)"도 테스트했다는 점. 쇼핑 실험에선 정가 $128의 낡은 Lululemon ABC 팬츠를 ~$50에 맞추기 위해 세일품과 유사 dupes를 제안했고, 과정은 채팅 내 웹브라우저로 그대로 보였습니다. 시장도 반응했습니다 — Planet Fitness 주가는 약 10% 하락했습니다.

⚠️ 읽기 전용 실측으로, 실제 해지는 사용자가 직접 해야 합니다. 시장 반응은 시장 상황과 함께 보시기 바랍니다.

3위 · 신규 디테일

Global Entry용 5년 여행기록 정리

WSJ 니콜 응우옌의 실측이 재보도됐습니다(newsis, 9/29). Muse에 지메일을 읽기 전용으로 연결해 캘린더와 이메일을 뒤진 뒤, Global Entry 신청에 필요한 최근 5년의 해외여행 기록을 정리해냈습니다. 재보도에선 실패 사례도 함께 실렸는데, 헬스장 회원 추천 혜택을 물었을 때 본인과 무관한 미국 반대편 헬스장 할인을 가져온 사례가 포함됐습니다 — 실측의 솔직함이 느껴지는 대목입니다.

⚠️ Meta는 제공된 정보를 광고에 사용하지 않지만 모델 훈련에 활용할 수 있습니다(거부 가능). 연내 'Confidential VM'(대화 암호화) 도입이 예정돼 있습니다.

4위 · 시즌 이슈

홀리데이 시즌 에이전트 쇼핑 공방

Amazon이 AI 쇼핑 에이전트를 차단한 사유가 구체화됐습니다(10/1 보도): ① 에이전트가 자신을 식별하지 않고, ② 고객 자격증명을 보유한 것처럼 보이며 주문 내역에 접근하고, ③ Meta와 사전 협의가 없었다는 것입니다. 한편 Muse와 제휴한 리테일러는 Best Buy·Gap·Sephora·Walmart·Wayfair·Fanatics·DICK'S·American Eagle·Ulta·Michael Kors에 Shop Pay·PayPal까지 확대됐습니다. Salesforce는 이번 홀리데이 시즌 전자상거래 트래픽의 20%가 AI 채팅 에이전트에서 올 것으로 전망했고, Adobe 조사에 따르면 AI 경유 방문의 전환율은 54% 높습니다.

⚠️ 활용법 자체보다는 배경 뉴스 성격이 강해 비중을 조절했습니다.

5위 · 차순위

스마트홈 제어 — Home Assistant MCP

"외출 시 난방을 낮춰줘" 같은 지시가 단순 제안이 아니라 도구 호출로 직접 처리됩니다. 조건은 Home Assistant 인스턴스가 인터넷에서 도달 가능해야 한다는 점, 그리고 필요한 엔티티만 노출하고 민감한 행위는 승인을 유지하라는 신뢰 설계가 강조됩니다.

⚠️ 9/18 자료로 다소 오래됐고 실제 사용자 실측 증언은 아니어서 차순위로 배치했습니다.

📊 배경 지표
  • 출시 3주 만에 500만 다운로드(북미), 10/1 기준 미국 무료 앱 1위 유지 (Meta 공식 수치 아님 — TechTarget 보도)
  • 토큰 요금제: 무료 요금제는 주 최대 1억 토큰(Zuckerberg 발언, CNET 경유), Power 월 $20 = 주 5억, Maximum 월 $100 = 주 30억 (과금 기준은 토큰 사용량뿐; 정책 변경 가능)
  • Connect 이후 1주일 만에 커넥터 제작 신청 개발자 1,500명+ (Alexandr Wang 발표)
  • 예정: Shop Pay·1Password 커넥터, Confidential VM(대화 암호화)
📝 각주
  • Marketplace 주소 공유 사건 후속: Meta가 권한 체계를 검토 중이라는 보도가 나왔습니다(Guardian·dig.watch, 9/30).
  • Mac 개인정보 논란 후속: 기자(Jason Aten)와 Meta 임원의 반박전이 보도됐습니다(BusinessToday 종합, 9/29~30).
