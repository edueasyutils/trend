1 Muse와 함께 쓰는 "최고의 스킬 25선" — @okapi_fukugyo

X 포스트에서 이렇게 소개됐다. GitHub의 스킬 링크를 Muse에 주면 Muse가 자기 가상 머신에 직접 설치한다고 전한다. 분야는 디자인·비디오(Frontend Design, Canvas Design, Algorithmic Art, Theme Factory, Remotion Create), 문서(DOCX, PPTX, XLSX, PDF, Doc Coauthoring), 마케팅(Copywriting, SEO Audit, CRO, Emails, Social), 개발(Writing Plans, Subagent-Driven Development, Git Worktrees, MCP Builder, Skill Creator), 테스트(Webapp Testing, Systematic Debugging, TDD, Requesting Code Review, Verification Before Completion)까지 다섯 갈래다. 25개 모두 Muse 가상 머신에서 동작 확인했다고 주장하며, 일부는 환경 조정이 필요하고, Skill Creator의 평가 기능은 Claude Code용이라 쓸 수 없다고 덧붙인다.

같은 "스킬 갈래"로는 @jackluos3lpo의 68개 공식 내장 스킬 포스트가 11월 25·26일 검색 결과에 없다가 오늘 다시 등장했다(아래 5번 참조). 어제 Top 5의 @HoneyBiu AGENTS.md 팁까지 합치면, 스킬·설정 갈래가 이틀 연속 화제의 한 축을 이루고 있다.

주의: 나열된 스킬이 Muse에서 실제로 동작하는지는 작성자 주장 수준이다. 대부분 Claude Code용 공개 스킬이며, Muse 가상 머신 동작 확인 주장도 작성자 기준이다. X 원문은 직접 열람하지 못했고 미러 재확인 수준으로 썼다. 또 수집 시점마다 수치가 조금씩 달라, 아래 수치는 조회 시점 기준이다.

2 인스타그램 DM 속에 Muse가 들어온다 — Threads 신규 6건 묶음

Threads 포스트들에서 이렇게 소개됐다. Meta가 Muse AI 어시스턴트를 인스타그램 DM에 직접 도입했다고 전한다. 갈래는 세 가지다. 첫째, DM 안에서 Muse와 채팅하고 놓친 메시지를 따라잡는다. 둘째, 저장한 릴스를 실행 가능한 계획으로 전환한다. 셋째, 저장한 포스트를 컬렉션으로 자동 정리한다. @mattnavarra는 DM 안에서 채팅, 놓친 메시지 따라잡기, 저장 릴스를 실행 가능한 계획으로 전환하는 기능을 소개했고, @lindseygamble_은 'Smoky Mountains Fall Weekend Plan'에 오프트레일 팁을 추가하고 저장 포스트를 'New York Eats'·'Healthy Recipes' 같은 컬렉션으로 자동 정리하는 화면을 보여줬다고 전한다. @everydayaitutor는 저장한 레시피를 장보기 목록으로, 여행 릴스를 여행 계획으로 바꾸는 예시를 들었고, @museai.cases는 저장한 여행 포스트를 실제 여행 일정으로 전환한다고 전한다. @luisbolinao는 DM에서 포스트를 공유하고 Muse에 행동을 지시할 수 있다고 전하며 신발 특가 찾기를 예로 들었고, @igor.volovodivsky는 Muse가 사용자 허락 없이 게시·발송하지 않으며, 맡긴 작업을 잊거나 취소해 달라고 할 수 있다고 전한다.

어제 Top 5에 실렸던 @smm.toolbox와 @bolanosmediagroup의 같은 소식 포스트도 오늘 다시 등장해, 이 갈래는 11월 24~26일에 걸쳐 여덟 건이 몰린 셈이다.
